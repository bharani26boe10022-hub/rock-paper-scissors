# Rock Paper Scissors GUI (Tkinter)

A desktop-based Rock Paper Scissors game built in Python using `Tkinter`. Features a modular design with a custom round setup and an interactive graphical user interface.

## Features

- **Custom Target Score:** Set how many points are needed to win the match.
- **Interactive UI:** Dynamic graphics, colored score indicators, and status updates built with `Tkinter`.
- **Modular Code Base:** Separated into clear, reusable Python modules for setup, gameplay, and main execution.
- **Single-Player vs. AI:** Play against a computer-controlled opponent that makes random moves.
